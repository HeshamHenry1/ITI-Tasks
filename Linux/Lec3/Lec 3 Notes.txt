Change Permission ===> chmod 
- Symbolic
    u,g,o,a,r,w,x + ,- ,=
    Add Permission x for user 
        chmod u+x ~/Music/file 
    Remove Permission x for user , put group r only , remove all Permission other 
        chmod u-x,g=r,o= ~/Music/file 
    put all Permission 
        chmod a=rwx ~/Music/file 
    Add x for user ,group , other 
        chmod a+x ~/Music/file 
    check permission

        folder : ls -ld path
